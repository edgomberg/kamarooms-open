Задача для Владимира — Приоритет #1
Поднять сервер в Яндекс.Облаке
Вся следующая фаза строится на одном фундаменте: виртуальная машина в Яндекс.Облаке. Туда пойдут база данных (PostgreSQL), система автоматизации (n8n), дашборды, API-шлюз. Без этого сервера — нечего наполнять данными.

Это разовая задача на 2-3 часа. После — у нас есть место для всего что строим.
2 vCPU / 4 GB RAM Ubuntu 22.04 LTS 30 GB SSD Порты: 22, 80, 443, 5432, 5678 Регион: ru-central1-a
Почему это первым: каждый следующий шаг (данные из 1С, дашборды, автоматизация) требует места для хранения и обработки. Без сервера — всё лежит в Excel и никуда не двигается.
